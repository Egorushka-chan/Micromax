# IDEF1X-схема базы данных MicroMax

Файл `IDEF1X-схема-БД-MicroMax.svg` содержит IDEF1X-схему базы данных проекта MicroMax на русском языке. Схема составлена по текущей серверной модели данных и отражает фактические сущности MVP: складскую структуру, номенклатуру, остатки, складские операции, журнал операций, пользователей, роли и штрихкоды.

В схему включены следующие таблицы:

- `Warehouses`
- `StorageZones`
- `StorageCells`
- `Products`
- `StockBalances`
- `AppUsers`
- `Roles`
- `WarehouseUsers`
- `RefreshTokens`
- `WarehouseOperations`
- `OperationLogs`
- `Barcodes`

Служебная таблица `__EFMigrationsHistory` в схему не включалась, так как она не относится к предметной области микросклада.

Примечания по интерпретации схемы:

1. Все физические внешние ключи на схеме показаны как неидентифицирующие связи, поскольку во всех таблицах используются суррогатные первичные ключи `Id`.
2. Таблица `Barcodes` содержит полиморфную ссылку `EntityType + EntityId` на номенклатуру или ячейку хранения. Эта связь обозначена на схеме как логическая, так как она не оформлена отдельным внешним ключом SQL.
3. Для `Barcodes` в реализации дополнительно используются частичные уникальные индексы для активного значения штрихкода и для активного основного штрихкода сущности. Эти ограничения отмечены в пояснении, но не вынесены в отдельные альтернативные ключи диаграммы.
