# Демо-сценарий MVP MicroMax

## Назначение

Данный сценарий предназначен для демонстрации дипломного MVP информационной системы управления микроскладом. Демонстрация показывает складскую структуру, номенклатуру, остатки, складские операции, журнал операций, серверную админ-панель и мобильное Android-приложение.

## Запуск серверной части

1. Запустить PostgreSQL:

```powershell
docker compose -f Database\docker-compose.yml up -d
```

2. Запустить сервер:

```powershell
dotnet run --project Server\MicroMax.Server\MicroMax.Server.csproj --urls http://localhost:5101
```

3. Открыть админ-панель:

```text
http://localhost:5101
```

При первом запуске сервер создаёт демонстрационные данные: склад, зоны хранения, ячейки, номенклатуру, остатки, роли и пользователя.

## Проверка основных сценариев

1. Открыть админ-панель и убедиться, что отображается отчёт по текущим остаткам.
2. Выполнить операцию приёмки для одной из позиций номенклатуры.
3. Убедиться, что количество в отчёте по остаткам увеличилось.
4. Выполнить операцию перемещения между двумя ячейками.
5. Убедиться, что остаток уменьшился в исходной ячейке и увеличился в целевой.
6. Выполнить операцию списания.
7. Убедиться, что операция отображается в журнале операций.

## Запуск мобильного приложения

Android-приложение подключается к серверу по адресу:

```text
http://10.0.2.2:5101
```

Этот адрес используется Android Emulator для обращения к `localhost` хостовой машины. Перед запуском приложения сервер должен быть доступен на `http://localhost:5101`.

## Командный помощник

Для онлайн-командного помощника необходимо задать переменную окружения:

```powershell
$env:OPENAI_API_KEY = "<ключ OpenAI API>"
```

Примеры команд:

- `Где лежат перчатки?`
- `Сколько осталось скотча?`
- `Прими 5 перчаток в A-1`
- `Перемести 3 перчатки из A-1 в B-1`
- `Спиши 2 болта из B-1`

Операции изменения остатков через помощника требуют подтверждения пользователя.
